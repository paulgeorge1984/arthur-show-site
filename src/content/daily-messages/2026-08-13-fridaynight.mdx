    <h2>神は教会の箱の中だけにおられない</h2>
    <p>十字架は、建物の中に神を閉じ込めるための記号ではない。アーサーは、ゴッホが描いた世界にも触れながら、神は教会の中だけにおられる方ではなく、箱の中に入れられる存在でもないと語る。神の息を受けた人間そのものが、神の臨在を受け取る器として造られている。</p>

    <div class="msg-quote"><p>教会の中だけに神はいない。神は箱の中に入れられる存在じゃない。</p><span class="q-src">ARTHUR HOLLANDS / 07:23</span></div>
    <p>だから、礼拝の時間だけが神と出会う時間ではない。仕事の場、家庭、移動の途中、眠りにつく前にも、神は共におられる。パラダイスを遠くへ探しに行く前に、今日この場所で神の臨在に心を開くことが、最初の一歩になる。</p>

    <h2>見えている自分より、心の奥を主に明け渡す</h2>
    <p>メッセージの中で語られる氷山のたとえは、私たちの自己理解を揺さぶる。水面の上に見えている部分は、言葉、奉仕、態度、信仰者としての外側の姿だ。しかし水面下には、恐れ、怒り、自己防衛、赦せなさ、認められたい思いが隠れている。人は外側を見るが、イエスは心の内側を見る。</p>

    <figure class="article-photo">
      <img src="/img/daily/20260813-fridaynight/03-iceberg-heart-illustration.jpg" alt="水面上と水面下の氷山を描いた心の奥の比喩の挿絵" loading="lazy" />
      <figcaption>水面下に隠れた心の奥まで、主の光が届くことを表す挿絵。</figcaption>

    <div class="msg-quote"><p>この氷山の氷河の上のお前じゃない。水に沈んでいるお前なんだ。</p><span class="q-src">ARTHUR HOLLANDS / 14:43</span></div>
    <p>ローマ人への手紙8章が示すように、肉の思いは神に逆らう方向へ私たちを引っ張る。一方、御霊の思いは、いのちと平安へ導く。主の前で取り繕うのではなく、まだ見せたくない部分まで差し出すとき、恵みは水面下にも届いていく。</p>

    <h2>重荷を負ったまま、イエスのくびきを受ける</h2>
    <p>「疲れている者、重荷を負っている者、私のところに来なさい」というマタイ11章の招きは、頑張り切った人へのご褒美ではない。疲れたまま、重荷を抱えたまま来てよいという招きだ。アーサーは自身の首の痛みやレスリングの経験を振り返りながら、イエスのくびきは私たちを壊すためではなく、主と歩幅を合わせるためのものだと語る。</p>

    <figure class="article-photo">
      <img src="/img/daily/20260813-fridaynight/04-yoke-and-rest.jpg" alt="イエスのくびきと安息について語るアーサー・ホーランド" loading="lazy" />
      <figcaption>自分の力で人生を支配するのではなく、柔和でへりくだったイエスと歩む安息を語る。</figcaption>
    </figure>

    <div class="msg-quote"><p>すべて疲れている人、重荷を負っている人、私のところに来なさい。</p><span class="q-src">マタイの福音書 11:28 / MESSAGE QUOTE</span></div>
    <p>神は、私たちの自我を打ち砕くために苦しみを求めているのではない。自分だけで背負い、自分だけで正しさを証明しようとする歩みから、主と共に歩む歩みへ導いてくださる。柔和さとは弱さではなく、神に主導権を返した人の強さだ。</p>

    <h2>十字架の隣で、今日のパラダイスが開かれた</h2>
    <p>ルカの福音書23章で、イエスは十字架の隣にいた強盗に「あなたは今日、私と共にパラダイスにいます」と告げた。その人には、誇れる宗教的実績も、人生をやり直す時間もなかった。ただイエスに向き直り、助けを求めた。その瞬間、パラダイスは「いつか」ではなく「今日」の約束になった。</p>

    <div class="msg-quote"><p>まことにあなたに告げます。あなたは今日、私と共にパラダイスにいます。</p><span class="q-src">ルカの福音書 23:43 / MESSAGE QUOTE</span></div>
    <p>この「今日」は、死後の希望を否定する言葉ではない。むしろ、死を越える希望が今この瞬間にも私たちを支えるという宣言だ。イエスが共におられるなら、罪や後悔で閉ざされた場所にも、神の国の扉は開かれる。</p>

    <h2>聖書が語る三つのパラダイス</h2>
    <p>アーサーは、新約聖書で「パラダイス」という言葉が三回登場することに注目する。第一は、十字架の強盗に語られた今日の約束。第二は、パウロが第三の天に引き上げられ、言葉にできないものを聞いた体験。第三は、黙示録で勝利を得る者に約束された、神のパラダイスにある命の木だ。</p>
    <p>創世記のエデンの園で始まった聖書の物語は、黙示録の新しいエデンへ向かう。そこでは神と小羊の臨在が十分で、神殿を必要としない。未来に完成するパラダイスの約束は、今日の私たちに「神の臨在こそがいのちだ」と教えている。</p>

      <figcaption>エデンから新しいエデンへ続く、神の臨在と命の木を表す挿絵。</figcaption>

    <div class="msg-quote"><p>神が共にいるってことはパラダイスだよってことなんですよ。</p><span class="q-src">ARTHUR HOLLANDS / 83:45</span></div>
    <p>パラダイスを場所だけで考えると、神の臨在を見失う。神が共におられることそのものが、パラダイスの本質である。だから私たちは、神の臨在を未来へ先送りせず、今日の祈りと従順の中で味わい始めることができる。</p>

    <h2>ヤコブにも語られた「私はあなたと共にいる」</h2>
    <p>ヤコブは、兄を欺き、祝福を奪い、命を狙われながら逃げていた。立派な信仰者として整ってから神に会ったのではない。石を枕にして眠った旅の途中で、天と地を結ぶ梯子を見、主から「私はあなたと共にあり、あなたがどこへ行ってもあなたを守る。決してあなたを捨てない」と聞いた。</p>

    <figure class="article-photo">
      <img src="/img/daily/20260813-fridaynight/06-jacob-ladder-illustration.jpg" alt="石を枕に眠るヤコブと天へ伸びる梯子を描いた挿絵" loading="lazy" />
      <figcaption>整ってからではなく、逃げている途中のヤコブにも、神は共にいると約束された場面を描いた挿絵。</figcaption>
    </figure>

    <div class="msg-quote"><p>見よ、私はあなたと共にあり、あなたがどこへ行ってもあなたを守り、決してあなたを捨てない。</p><span class="q-src">創世記 28:15 / MESSAGE QUOTE</span></div>
    <p>神は、私たちの失敗を見落としているのではない。むしろ心の奥を取り扱いながら、共に歩み、約束を成し遂げてくださる。パラダイスは、問題がすべて消えた場所ではない。問題のただ中で、神が見捨てず共におられることを知る場所だ。</p>

    <h2>明日ではなく、昨日でもなく、今日</h2>
    <figure class="article-photo">
      <img src="/img/daily/20260813-fridaynight/07-today-prayer.jpg" alt="神が共にいる今日を語り祈りへ招くアーサー・ホーランド" loading="lazy" />
      <figcaption>「今日、あなたは私と共にパラダイスにいる」と祈りへ招く。</figcaption>
    </figure>
    <p>メッセージの終わりに、アーサーは祈りへと招く。「今日、あなたは私と共にパラダイスにいる。イエス様があなたと共にいる。パラダイスがあなたの中にある」。これは感情を無理に盛り上げるための言葉ではない。御言葉に基づいて、神の臨在を受け取るための信仰の応答だ。</p>
    <p>今日、赦せない人のために祈る。今日、隠していた心を主に告白する。今日、疲れたままイエスのもとへ行く。敵を愛し、赦すことも、まず主に赦された者として歩き始めることから生まれる。神が共におられる「今日」を、今日の一歩で受け取ろう。</p>
