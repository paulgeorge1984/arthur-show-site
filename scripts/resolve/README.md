# Resolve スクリプト

デイリー編集の DaVinci Resolve Studio 側作業を自動化するスクリプト置き場。
Resolve が動いている M1 MAX 上で実行する。

## apply_cam02_iroate.py

cam02 系クリップへ `iroate_227.cube` を **キー処理後 25% ミックス**で一括適用する。

### 前提

スレッドで確定した方針をそのまま実装している。

- `cam2Y` は維持する。`cam2X` は赤み・彩度がさらに強くなるので使わない
- `iroate_227` は 100% だと顔と赤襟が過彩度・白飛び／黒潰れ気味になる。25% で寒色感だけが自然に緩和され、cam01 に近づく
- 再開後の B06 だけ、25% に加えて露出・WB の個別補正が必要

25% ミックスはノードの Key Output Gain で作るが、これはスクリプト API から
直接触れない。そのため **25% を仕込んだ基準クリップのノードグラフを
`CopyGrades` で配る**という形にしてある。Codex が現在位置と B06 代表カットに
入れた 25% が、そのまま基準クリップとして使える。

### 手順

1. **複製したプレビュー側**のタイムラインを開く。元 R2 は開かない
2. iroate 25% が入っているクリップに再生ヘッドを合わせる
3. B06 の露出・WB 補正も入れるなら、基準クリップのノードグラフの末尾に
   **空のノードを 1 つ足しておく**（その番号を `--cdl-node` に渡す）
4. 対象を確認する（既定は dry-run で、何も書き換えない）

   ```sh
   python3 scripts/resolve/apply_cam02_iroate.py
   ```

5. 表示された対象数と cam2Y / B06 の振り分けが合っていれば適用する

   ```sh
   python3 scripts/resolve/apply_cam02_iroate.py --apply --backup
   ```

6. 再開後 B06 に露出・WB 補正も足す場合

   ```sh
   python3 scripts/resolve/apply_cam02_iroate.py --apply --backup \
       --restart-frame 123456 --cdl-node 4 --b06-gain 1.06 --b06-wb 0.02
   ```

### 元 R2 を壊さないための安全策

- 既定は dry-run。`--apply` を付けない限り一切書き換えない
- `--backup` で適用前にタイムラインを複製する
- `--require-name プレビュー` のように指定すると、タイムライン名にその文字列が
  含まれない場合は中止する（元 R2 を開いたまま実行する事故を防ぐ）

### 主なオプション

| オプション | 意味 |
|---|---|
| `--apply` | 実際に書き換える。無指定なら dry-run |
| `--backup` | 適用前にタイムラインを複製 |
| `--require-name SUBSTR` | タイムライン名に SUBSTR が無ければ中止 |
| `--ref-start FRAME` | 基準クリップを開始フレームで指定（既定は再生ヘッド位置） |
| `--restart-frame FRAME` | このフレーム以降を再開後 B06 として扱う（既定は名前で判定） |
| `--skip-post-restart` | B06 には基準グレードをコピーしない |
| `--cdl-node N` | B06 の露出・WB 補正を入れるノード番号 |
| `--b06-gain X` | B06 の露出倍率。`1.06` で約 +0.08 stop 相当 |
| `--b06-wb X` | B06 の WB。正で暖色、負で寒色。`0.02` 前後が目安 |

`--b06-gain` と `--b06-wb` の既定値は 1.0 / 0.0（無補正）にしてある。
実際の数値は Color ページで B06 代表カットを見ながら詰めること。
